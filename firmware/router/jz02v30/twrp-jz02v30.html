Cara Pasang TWRP 2.8.5.0 untuk JZ02V30 MSM8916

Assalamu Alaikum....
Bagi kamu yang punya perangkat JZ02V30 berbasis chipset MSM8916, artikel ini akan membahas cara memasang TWRP 2.8.5.0 di perangkat tersebut. Ada beberapa skenario yang perlu dipahami, terutama apakah perangkatmu sudah root atau belum.

Catatan penting: Untuk JZ02V30 yang belum root, flash recovery harus via EDL/QDL. Jika flash via fastboot, ada pengguna yang menjelaskan bahwa fastboot stok di JZ02V30 ini memang tidak berfungsi sebagaimana mestinya — penjelasan lengkapnya bisa dibaca di referensi aboot UZ801 di GitHub.

Kondisi Awal Perangkat

1. Belum Root (Tanpa PC)

Jika kamu ingin melakukan root terlebih dahulu tanpa PC, bisa membaca panduan berikut:

👉 Cara Root H760R MSM8916 Versi Board JZ02_V30

Atau jika ingin root dengan bantuan PC, silakan cari artikel lain di internet yang membahas root MSM8916 via PC.

2. Belum Root (Via Fastboot)

Untuk yang belum root, flash recovery via fastboot tidak akan berhasil karena fastboot stok pada JZ02V30 tidak berfungsi semestinya. Solusi fastboot yang berhasil mengharuskan aboot diflash ke stok aboot milik UZ801, yang pada akhirnya tetap harus menggunakan Program EDL/QDL. Detail teknis dan pengalaman pengguna terkait hal ini dapat dilihat di referensi aboot UZ801 (ardiesan/JZ02_V30).

3. Sudah Root

Jika JZ02V30 kamu sudah root, kamu bisa langsung mengikuti langkah-langkah di bawah ini untuk memasang TWRP 2.8.5.0.

Langkah Pemasangan TWRP 2.8.5.0 (Sudah Root)

Langkah 1 — Unduh TWRP

Unduh file TWRP 2.8.5.0 untuk JZ02V30 melalui tautan berikut:

⬇ Unduh Twrp2850-jz02v30

Setelah diunduh, ekstrak file zip tersebut untuk mendapatkan file jz02v30-twrp2850.img.

Langkah 2 — Masuk ke ADB Shell

Masuk ke ADB shell menggunakan PC, atau gunakan ADBify jika tanpa PC.

Jalankan perintah berikut untuk memflash recovery:

dd if=/sdcard/jz02v30-twrp2850.img of=/dev/block/mmcblk0p26

Atau bisa juga menggunakan perintah alternatif berikut:

cat /sdcard/jz02v30-twrp2850.img > /dev/block/mmcblk0p26

Setelah itu, jalankan perintah sync untuk memastikan semua data tertulis dengan benar, lalu reboot recovery.

Langkah 3 — Install ZIP via TWRP (Opsional)

Jika kamu ingin menginstall file zip (misalnya mysu.zip untuk root), gunakan perintah berikut di TWRP:

twrp install /sdcard/mysu.zip

Ringkasan Perintah

# Flash TWRP via ADB Shell dd if=/sdcard/jz02v30-twrp2850.img of=/dev/block/mmcblk0p26 # Alternatif cat /sdcard/jz02v30-twrp2850.img > /dev/block/mmcblk0p26 # Sync dan reboot sync reboot recovery # Install zip via TWRP twrp install /sdcard/myChainfiresu.zip
⚠ Disclaimer: Jika terjadi kerusakan pada perangkat, kami tidak bertanggung jawab. Anda sudah tahu risikonya, kan? Lakukan dengan hati-hati dan pastikan semua langkah dipahami sebelum eksekusi.
