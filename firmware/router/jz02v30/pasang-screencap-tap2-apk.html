Aplikasi Screencap tap2 di 4G-UFI-xxxx (JZ02-V30 MSM8916)

Sebelum aplikasi bisa dipasang dan digunakan, perangkat UFInya harus memiliki akses root terlebih dahulu (Chainfire, Magisk, atau root bawaan). Untuk perangkat (JZ02-V30 MSM8916), saya sudah menulis panduan lengkap cara root-nya di sini:

👉 Cara Root JZ02_V30 MSM8916 Versi Board

Bagi yang sudah root, silakan lewati artikel root tersebut. Bagi yang punya PC, juga bisa melewati langkah ini karena di PC sudah tersedia ARDC (Android Remote Debug Console).

Jika UFI 4G Sudah Root — Ikuti Langkah Berikut

Persiapan

  1. Pasang ADBify di HP yang mendukung OTG.
    👉 ADBify di Google Play Store
    Siapkan juga kabel USB OTG.
  2. Unduh aplikasi ScreenTap (ScreenJZ02).
    👉 Download cc.yadisupri.screenjz02.apk
    Simpan file APK ke folder Download di HP.
  3. Hubungkan kabel OTG ke HP.

Langkah 1 — Deteksi Device via ADB

  • Buka ADBify
  • Izinkan koneksi Android ADB
  • Pastikan device terdeteksi dengan perintah:
adb devices

Langkah 2 — Pasang APK ScreenJZ02 di UFI

APK ScreenJZ02 harus dipasang dulu di perangkat UFI. Ada dua cara:

Cara A — Push lalu install manual:

adb push /sdcard/Download/cc.yadisupri.screenjz02.apk /sdcard/myapp.apk
adb shell pm install /sdcard/myapp.apk

Cara B — Install langsung dari folder Download:

adb install /sdcard/Download/cc.yadisupri.screenjz02.apk
⚠️ Perhatikan: pastikan nama file APK sama persis dengan yang ada di folder Download HP. Jika berbeda, sesuaikan perintahnya.

Langkah 3 — Buka Magisk & Izinkan Akses Root (Hanya Sekali)

Jalankan aplikasi ScreenJZ02, lalu buka Magisk untuk memberikan izin root:

adb shell am start -n cc.yadisupri.screenjz02/.MainActivity
sleep 3
adb shell am start com.topjohnwu.magisk/.core.SplashActivity

Ambil gambar (screenshot) untuk keperluan penentuan koordinat tombol Grant/Allow:

adb shell screencap /sdcard/king.png && adb pull /sdcard/king.png /sdcard/king.png
✅ Langkah ini hanya dilakukan SEKALI.
Tujuan membuka Magisk di sini adalah untuk mengizinkan permintaan akses root aplikasi ScreenJZ02. Setelah izin diberikan dan perangkat di-reboot, kamu tidak perlu lagi membuka Magisk atau mengulangi langkah ini di kemudian hari.

Langkah 4 — Ambil Koordinat & Klik Tombol Izinkan

  1. Buka situs pengambil koordinat:
    👉 https://yadisupri.cloud-ip.cc/tool/getXy.html
  2. Upload gambar king.png tadi, lalu salin koordinat (x y) posisi tombol Grant/Allow pada popup Magisk.
  3. Kembali ke ADBify, ketik:
adb shell input tap x y
Ganti x dan y dengan koordinat hasil dari situs tadi.

Setelah izin diberikan, reboot perangkat sekali saja.

Akses Screencap di Kemudian Hari

Setelah izin root permanen tersimpan, untuk mengakses Screencap lagi kamu cukup menjalankan aplikasinya lewat ADB (tanpa perlu buka Magisk lagi):

adb shell am start -n cc.yadisupri.screenjz02/.MainActivity

Lalu buka browser di HP yang terhubung ke jaringan, akses:

http://192.168.100.1:9009

Membuat Akses Permanen (Tanpa ADB Setiap Kali)

Cara di atas memang merepotkan karena harus lewat ADB setiap kali ingin membuka Screencap. Jika ingin permanen, kita bisa mengaktifkan adbd wireless dengan menambahkan properti berikut:

persist.adb.tcp.port=5555

Setelah itu, gunakan aplikasi ADB WiFi untuk mengakses perangkat secara nirkabel:

👉 ADB WiFi (Remote Debugger)

Dengan begitu, kamu tidak perlu lagi menghubungkan kabel OTG setiap kali ingin menjalankan perintah ADB — cukup melalui koneksi WiFi.
